# 🚗 AutoValet & Inspection Web Application

> **Live Demo:** [auto-valet-app-v1.vercel.app](https://auto-valet-app-v1.vercel.app)

An interactive LegalTech MVP designed for automated vehicle valet pick-up, service intake, and digital liability assignment. Built as a case study in **Tech Law & Digital Contracting**.

---

## 📌 Features
* **Vehicle Intake Workflow:** Streamlined capture of owner data, vehicle registration, and service schedules.
* **Tech Law Integration:** Embedded digital liability waiver and transfer-of-responsibility terms.
* **Mobile-Responsive UI:** Clean, intuitive interface built with raw HTML, CSS, and vanilla JS.
* **Automated Deployment:** CI/CD deployment pipeline via Vercel connected to GitHub repository.

---

## ⚖️ Legal & Governance Note
This MVP demonstrates how legal intake forms can be digitized to reduce operational friction in automotive logistics while enforcing verifiable digital consent before service handover.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Deployment:** Vercel
* **Version Control:** Git / GitHub
